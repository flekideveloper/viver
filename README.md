# VIVER

Мінімалістичний робочий простір для авторів відео, стримерів і контент-креаторів.

**Сайт:** https://flekideveloper.github.io/viver/

## Можливості v0.2

- **Огляд** — найближчі справи та запланований контент.
- **Планер** — список і дошка етапів: Ідея → Сценарій → Запис → Монтаж → Готово → Опубліковано. Можна переносити картки між етапами.
- **Календар** — окрема сторінка в лівому меню; повний місячний вигляд, події дня поруч, перетягування відео для зміни дати, швидке додавання контенту й нагадувань.
- **Чеклісти** — окремі завдання для кожного контент-запису з відмітками виконання. Старий стан `draft` збережений і відображається в колонці «Сценарій» без примусової зміни даних.
- **Нагадування** — разові, щоденні, щотижневі, щомісячні й за вибраними днями тижня. Коли відмічаєш повторюване нагадування виконаним, воно переноситься на наступну дату. Сповіщення браузера працюють **лише коли VIVER відкритий**.
- **Дошка ідей** — перетягування й редагування стікерів, шість кольорів, групи, локальні зображення, HTTPS-посилання та зв'язки між нотатками. Меню «···» відкриває розширені дії.
- **Платформи й статистика** — YouTube, TikTok, Twitch, X (Twitter). Перегляд **лише реальних імпортованих значень** із CSV/JSON-файлу, фільтр платформи й показника, графік зміни значень. Автоматичних API-підключень і OAuth поки немає.
- **Пошук** — Ctrl+K.
- **Налаштування** — чотири теми (темна, світла, сіра й космічна), миттєве перемикання зі збереженням вибору, мови, JSON-бекапи, імпорт і очищення.

## Як імпортувати статистику

Відкрий **Платформи → Шаблон CSV**, заповни файл власними показниками й обери **Імпорт звіту**.

Формат:

```csv
date,platform,views,followers,likes,comments,shares
2026-10-20,youtube,100,10,4,1,0
2026-10-21,youtube,200,12,8,2,1
```

Поля `date` (YYYY-MM-DD), `platform` (youtube, tiktok, twitch, x) і хоча б одне числове поле обов'язкові. Дані за однакові день і платформу замінюються останнім імпортованим рядком. Метрики **не завантажуються автоматично**; історичний графік показує саме те, що внесено у файл. Для офіційної автоматичної аналітики потрібні API-доступи, OAuth і захищений бекенд.

## Дані й приватність

Усі дані залишаються в localStorage браузера за ключем `viver-workspace-v1`. Поточна версія зчитує записи попередньої v0.1 і доповнює їх новими полями без видалення. Додані зображення стискаються перед локальним збереженням і включаються в JSON-бекап. Локальний простір має обмеження обсягу, тому регулярно створюй резервну копію; дані не синхронізуються між пристроями.

Ніхто не отримує пароль від соцмереж через VIVER. Усі посилання в стікерах обмежено протоколом HTTPS. Акаунти ще не підключаються.

## GitHub Actions

- `.github/workflows/deploy.yml` — автоматичне публікування на GitHub Pages із `main`, без додаткового сервера.
- `.github/workflows/verify.yml` — незалежна перевірка взаємодії та сумісності зі старими локальними даними; не блокує публікацію сайту.
- `tests/smoke.cjs` — тести з jsdom, запуск локально: `npm install --no-save jsdom@26 && node tests/smoke.cjs`.

В інших проєктах, базах і Cloudflare-ресурсах змін не робили.
