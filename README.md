# VIVER

Простий робочий простір для творців контенту.

**Сайт:** https://flekideveloper.github.io/viver/

## Що працює

- **Огляд** — найближчі нагадування, контент-план і кількість стікерів.
- **Планер** — створення, редагування, фільтри, етапи й видалення записів.
- **Нагадування** — дата, час, пріоритет, виконання й редагування. Сповіщення браузера працюють, лише поки VIVER відкритий.
- **Дошка ідей** — біла дошка зі стікерами: шість кольорів, перетягування, редагування, дублювання, видалення та масштаб.
- **Пошук** — Ctrl+K: знаходить записи, нагадування й текст стікерів.
- **Налаштування** — світла/темна тема, українська й англійська мови, експорт та імпорт JSON.

### Щодо соцмереж

У вкладці **Платформи** показані YouTube, TikTok, Twitch та X. Поки що це неактивні інтеграції: жодні акаунти не підключені, реальна аналітика недоступна. Для OAuth і статистики потрібен окремий захищений бекенд та офіційні API. Сайт не показує вигаданих метрик і не запитує паролів від соцмереж.

### Дані

Записи зберігаються локально за ключем `viver-workspace-v1` у браузері. Після оновлення інтерфейсу старі записи читаються тим самим форматом. Дані не синхронізуються між пристроями. Рекомендується періодично зберігати резервну копію в Settings.

## Розгортання

`.github/workflows/deploy.yml` публікує сайт через **GitHub Actions → GitHub Pages** за кожного push у `main`. Код сайту — `index.html`, `style.css`, `app.js`.

VIVER не використовує сервери, бази чи облікові записи інших проєктів.
