# VIVER

Мінімалістичний робочий простір для авторів відео, стримерів і контент-креаторів.

**Сайт:** https://flekideveloper.github.io/viver/

## Можливості v0.6

- **Огляд** — найближчі справи, запланований контент і переходи безпосередньо до редагування потрібного запису.
- **Планер** — списки без постійно відкритих форм (кнопка «Новий запис» відкриває редактор) та дошка етапів: Ідея → Сценарій → Запис → Монтаж → Готово → Опубліковано. Можна переносити картки між етапами.
- **Календар** — окрема сторінка в лівому меню; місячний вигляд, події дня, перетягування відео на інший день, створення контенту й нагадувань. Повторювані нагадування показуються також у майбутніх датах.
- **Чеклісти** — окремі завдання для кожного контент-запису з відмітками виконання. Старий стан `draft` збережений і відображається в колонці «Сценарій» без примусової зміни даних.
- **Нагадування** — редактор відкривається за кнопкою; разові, щоденні, щотижневі, щомісячні й за вибраними днями тижня. Коли відмічаєш повторюване нагадування виконаним, воно переноситься на наступну дату. Сповіщення браузера працюють **лише коли VIVER відкритий**.
- **Дошка ідей** — перетягування й редагування стікерів, шість кольорів, групи, локальні зображення, HTTPS-посилання та зв'язки між нотатками. Меню «···» відкриває тільки потрібні дії, а групу й HTTPS-посилання можна редагувати в окремому діалозі.
- **Платформи** — підтримка офіційного Google OAuth для YouTube. Підключений канал отримує **живу статистику через YouTube Data API**: загальні перегляди, округлену кількість підписників, публічні відео, останні публікації й графік фактично зібраних щоденних знімків. Окремий імпорт CSV/JSON збережений для всіх платформ. TikTok, Twitch і X очікують власних OAuth-ключів.
- **Пошук** — Ctrl+K; результати відкривають потрібний запис або стікер, а не просто розділ.
- **Налаштування** — чотири теми (темна, світла, сіра й космічна), миттєве перемикання зі збереженням вибору, мови, JSON-бекапи, імпорт і очищення.

## Як імпортувати статистику

Відкрий **Статистика → Шаблон CSV**, заповни файл власними показниками й обери **Імпорт звіту**.

Формат:

```csv
date,platform,views,followers,likes,comments,shares
2026-10-20,youtube,100,10,4,1,0
2026-10-21,youtube,200,12,8,2,1
```

Поля `date` (YYYY-MM-DD), `platform` (youtube, tiktok, twitch, x) і хоча б одне числове поле обов'язкові. Дані за однакові день і платформу замінюються останнім імпортованим рядком. Метрики **імпортованих звітів** не завантажуються автоматично: їхній графік показує лише те, що внесено у файл. Статистика підключеного YouTube доступна **окремо вище** через серверний API. Не плутай ці два різні джерела.

## Дані й приватність

Плани, нагадування, стікери та ручні звіти залишаються в localStorage браузера за ключем `viver-workspace-v1`. Поточна версія зчитує записи попередньої v0.1 і доповнює їх новими полями без видалення. Додані зображення стискаються перед локальним збереженням і включаються в JSON-бекап. Локальний простір має обмеження обсягу, тому регулярно створюй резервну копію; дані не синхронізуються між пристроями.

Ніхто не отримує пароль від соцмереж через VIVER. Усі посилання в стікерах обмежено протоколом HTTPS. Для YouTube вже працює офіційне OAuth-підключення через Cloudflare; токени зберігаються в окремій D1 зашифрованими. Серверні знімки YouTube зберігаються до відключення облікового запису. Для інших платформ потрібні відповідні OAuth apps і Secrets; див. [auth-worker/SETUP.md](auth-worker/SETUP.md).

## GitHub Actions

- `.github/workflows/deploy.yml` — автоматичне публікування на GitHub Pages із `main`, без додаткового сервера.
- `.github/workflows/verify.yml` — незалежна перевірка взаємодії, OAuth backend та сумісності зі старими локальними даними; не блокує публікацію сайту.
- `tests/smoke.cjs` — тести з jsdom, запуск локально: `npm install --no-save jsdom@26 && node tests/smoke.cjs`.

В інших проєктах, базах і Cloudflare-ресурсах змін не робили.

## OAuth backend

Worker: `viver-auth.flekideveloper.workers.dev`. Окремий D1: `viver-oauth-db`. Код: [auth-worker/src/index.js](auth-worker/src/index.js). Ключі шифрування та OAuth-клієнтів додаються тільки у Cloudflare Secrets, не в репозиторій. Без ключів UI показує чесний статус «Потрібні ключі API» й кнопки підключення неактивні. Облікові записи VIVER поки не підтримуються: OAuth-прив'язки локальні для конкретного браузера. Статистика YouTube кешується на Worker приблизно на **10 хвилин** для обмеження API-квоти, а щоденні знімки зберігаються лише коли сторінка звертається до API. У Google режим Testing може обмежувати строк роботи refresh-токена.
